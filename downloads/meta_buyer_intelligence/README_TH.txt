Meta Buyer Intelligence — คู่มือชุด Windows

เริ่มใช้งาน
1. คลิกขวาไฟล์ ZIP แล้วเลือก Extract All / แยกทั้งหมด
2. เปิดโฟลเดอร์ที่แยกไฟล์แล้ว ไม่เปิดโปรแกรมจากภายใน ZIP
3. ดับเบิลคลิก start_meta_buyer.bat
4. เบราว์เซอร์จะเปิดแดชบอร์ดเอง ให้เปิดหน้าต่างดำค้างไว้ระหว่างใช้งาน
5. หากเกิดข้อผิดพลาด หน้าต่างดำจะค้างข้อความไว้ ส่งเฉพาะข้อความผิดพลาดให้ตรวจ

ต้องมี Python 3.9 ขึ้นไป ตัวเปิดจะตรวจให้และแจ้งหากไม่พบ
ดาวน์โหลด Python สำหรับ Windows: https://www.python.org/downloads/windows/
โปรแกรมชุดนี้ใช้ Python standard library ไม่ต้อง pip install เพิ่ม
ไฟล์โปรแกรมชื่อ meta_buyer_intelligence.py.txt ตามนามสกุลเดิมที่ขอ
ถ้าจะเปิดเองใน Command Prompt ให้ใช้:
py "meta_buyer_intelligence.py.txt"

ใช้ข้อมูลและโทเค็นเดิม
หยุดโปรแกรมเก่าก่อนย้ายข้อมูลหรือคัดลอกฐานข้อมูล
คัดลอก config.env หรือ .env เดิมมาไว้ข้าง start_meta_buyer.bat
หากต้องการใช้ข้อมูลเดิม คัดลอก mbi.db และ .mbi_secret เดิมมาด้วย
ถ้าฐานข้อมูลมีไฟล์ mbi.db-wal / mbi.db-shm อยู่ ให้เก็บชุดเดิมครบไว้ก่อน
อย่าลบไฟล์ต้นฉบับจนกว่าจะเปิดข้อมูลในชุดใหม่สำเร็จ
หาก config.env กำหนด DB_PATH อยู่ โปรแกรมจะใช้ตำแหน่งนั้นตามเดิม
APP_SECRET ต้องเป็นค่าเดิมที่ใช้กับข้อมูลส่วนตัวเก่า มิฉะนั้นถอดข้อมูลเดิมไม่ได้
เก็บโทเค็นและไฟล์ตั้งค่าไว้ที่เครื่องคุณ ไม่ส่งไฟล์เหล่านี้ในแชต
ถ้าไม่มีไฟล์ตั้งค่า ให้คัดลอก config.example.env เป็น config.env แล้วเติมค่าที่เครื่องคุณ
อย่าทับ config.env / .env ที่ตั้งค่าใช้งานไว้แล้วด้วยไฟล์ตัวอย่าง

เมนูรับออเดอร์จากแชต
ก่อนเชื่อม Webhook ให้วางข้อความลูกค้าในแบบฟอร์มเพื่อทดสอบ
ใช้รหัสแชตเดิมสำหรับข้อมูลของออเดอร์เดียวกัน
ข้อความมีที่อยู่จัดส่งจะสร้างออเดอร์ CONFIRMED ไม่ใช่ยืนยันรับเงินหรือส่งสำเร็จ
ระบบเก็บยอดรวมที่ระบุในข้อความ หรือยอดแพ็กเกจที่ตั้งไว้เมื่อรู้จำนวนและวิธีชำระ
ถ้าไม่ทราบยอด จะบันทึกออเดอร์ไว้พร้อมให้เติมยอด ไม่เดาราคา
ส่งข้อความเดิมซ้ำหรือแก้ที่อยู่จะไม่สร้างออเดอร์ซ้ำ
การซื้อรอบใหม่ใช้ข้อความ สั่งเพิ่ม/สั่งอีก/ซื้ออีก/ออเดอร์ใหม่
หรือเลือกเริ่มออเดอร์ใหม่ในแบบฟอร์ม
ปรับราคาแพ็กเกจและต้นทุนในเมนูตั้งค่าให้ตรงร้านก่อนใช้งานจริง

รับแชตอัตโนมัติ
Messenger: ตั้ง Callback HTTPS /webhooks/messenger ที่ Facebook Page/App
ใช้ META_APP_SECRET เดิมตรวจลายเซ็น และ WEBHOOK_VERIFY_TOKEN สำหรับตรวจ Callback
LINE OA: ตั้ง Callback HTTPS /webhooks/line และ LINE_CHANNEL_SECRET
ต้องเปิดสิทธิ์และสมัครรับข้อความกับแพลตฟอร์มจริงก่อน
Ads token อย่างเดียวไม่ทำให้ระบบอ่านข้อความของเพจได้
รองรับข้อความตัวอักษร ไม่อ่านที่อยู่จากรูป/เสียงและไม่ตรวจสลิปธนาคารอัตโนมัติ
ถ้าเปิดให้เข้าถึงจากภายนอก ต้องตั้ง APP_TOKEN และ HTTPS
ไม่ต้องเปลี่ยน META_ACCESS_TOKEN หรือวิธีต่ออายุโทเค็นเดิม

Flash Express
สร้างพัสดุในบัญชี Flash ของคุณ แล้วผูกเลขพัสดุในเมนู Flash Express
ขณะนี้นำเข้า CSV หรือรับสถานะที่แปลงเป็นรูปแบบของโปรแกรมได้
ยังไม่ได้เชื่อม API Flash จริง ต้องใช้สิทธิ์ API และเอกสารบัญชีประเทศไทยของคุณ
CSV หัวตารางตาม shipping_template.csv
status ใช้ SHIPPED, IN_TRANSIT, DELIVERED, REFUSED, RETURNED, COD_COLLECTED
event_time ใช้ ISO 8601 พร้อม timezone เช่น 2026-10-05T10:00:00+07:00
COD_COLLECTED ต้องมี cod_amount เป็นยอดรับจริงสะสมของพัสดุนั้น
DELIVERED แปลว่าส่งถึง ไม่ถือว่า Flash โอนเงิน COD แล้ว
ถ้าไม่ใส่ event_id โปรแกรมจะสร้างรหัสจากข้อมูลแถวเพื่อกันนำเข้าซ้ำ
รูปแบบ CSV นี้เป็นรูปแบบของโปรแกรม ไม่อ้างว่าเป็นไฟล์ส่งออกดั้งเดิมของ Flash

กราฟและ Lookalike
เลือกช่วงวันที่ แคมเปญ และตัวชี้วัดในเมนูแดชบอร์ดกราฟ
กราฟอัปเดตทุก 20 วินาทีเมื่อไม่ได้แก้ตัวกรอง
มี 27 ตัวชี้วัด รวมยอดสั่งซื้อจากแชต ออเดอร์ที่ส่งที่อยู่ และเงิน COD ตามวันรับจริง
ยอดขายยืนยันแยกจากเงินรับจริงและ Purchase ที่ Meta รายงาน
ตัวเลขเหลือหลังต้นทุนยังไม่รวมค่าใช้จ่ายบริษัท และต้องกรอกต้นทุนให้ครบ
ดาวน์โหลด CSV / SVG และพิมพ์เป็น PDF ได้
Lookalike อ่านกลุ่มเดิมผ่านโทเค็นเดิมเมื่อมีสิทธิ์ ไม่สร้างกลุ่มหรือแก้โฆษณา

ข้อจำกัดการใช้งานจริง
ทดสอบระบบจำลองและเบราว์เซอร์แล้ว ยังไม่ได้ทดสอบบัญชี Meta/Flash ของคุณ
ตรวจ permissions, API version, fields และ breakdowns กับเอกสารทางการก่อนใช้งานจริง
การเข้ารหัสข้อมูลส่วนตัวสืบทอด prototype จากต้นฉบับ ยังไม่ใช่ระบบ AES-GCM/KMS สำหรับ production
สำรองฐานข้อมูลและ key และเตรียมระบบเก็บข้อมูลส่วนตัวที่เหมาะสมก่อนใช้กับบริษัทถาวร
